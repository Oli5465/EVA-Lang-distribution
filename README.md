# EVA’Lang pour Windows

EVA’Lang permet de préparer des grilles d’évaluation orale et d’imprimer une fiche par étudiant.

## Installation

1. Téléchargez [l’installateur Windows x64](https://github.com/Oli5465/EVA-Lang-distribution/releases/latest/download/EVA-Lang-Installation-x64.exe).
2. Fermez EVA’Lang si une séance est ouverte, puis exécutez l’installateur.
3. Ouvrez **EVA-Lang** dans le menu Démarrer. La version installée figure dans **Paramètres → Autres**.

À partir de la version 0.1.1, EVA’Lang vérifie les mises à jour à chaque ouverture. Le lanceur contrôle l’empreinte du fichier téléchargé et le démarrage de la nouvelle version avant de l’activer. En l’absence de connexion, il ouvre la version installée.

Les [versions officielles](https://github.com/Oli5465/EVA-Lang-distribution/releases) proposent l’installateur, son empreinte SHA-256 et les sources correspondantes. L’archive de sources de la version 0.1.1 inclut la licence GNU AGPL v3, les notices des dépendances et les instructions de construction.

## Documents et désinstallation

Le dossier **Documents/EVA-Lang** accueille les fichiers de travail. Vous pouvez choisir une autre destination dans **Paramètres → Général**. Les bases qui contiennent vos grilles, listes et évaluations restent dans le profil de l’utilisateur.

Pour désinstaller le logiciel, fermez EVA’Lang puis ouvrez **Paramètres Windows → Applications → EVA’Lang → Désinstaller**. Vos bases et vos documents sont conservés.
